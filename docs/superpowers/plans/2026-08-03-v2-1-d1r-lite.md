# V2.1 D1-R-Lite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Execution amendment:** The user requires main-task-only execution. Do not use subagents. Keep one process, one worker, and all six numeric-thread variables at one.

**Goal:** Repair the audit identity contract in a new namespace and run an adaptive four-case/eight-audit screen that expands to at most 12 cases/16 target audits only when a family appears in at least three Stage A scenario representatives.

**Architecture:** New D1-R-Lite files import only safe reconstruction/compaction helpers from the unchanged D1 module. A strict new config and LV906-only manifest freeze the 8-to-16 protocol; a sequential runner performs real-runtime preflight, immutable case writes, and conditional Stage B; a read-only evaluator reproduces CSV/JSON/Chinese Markdown/hash reports.

**Tech Stack:** Python 3.12, NumPy, pytest, PowerShell, Git, and the frozen `evflex.pilot` runtime.
