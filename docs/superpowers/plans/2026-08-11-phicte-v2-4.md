# PHiCTE V2.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Subagents are excluded by the user. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an exploratory Physics-guided Hierarchical Conformal Transferability Envelope that learns a conservative fixed-schedule transferability lower bound from V2.2 and evaluates it retrospectively on V2.3A without new power-flow runs.

**Architecture:** One module extracts pre-call physical-margin and balanced-offer features, fits a sign-constrained L1-shrunk quantile regression with SciPy linear programming, performs scenario-isolated cross-fitting, and applies one-sided calibration. One test file locks behavior. Runtime writes only a JSON summary and CSV predictions; V2.3A outcomes are never used for fitting or tuning.

**Tech Stack:** Python 3.12, NumPy, SciPy `linprog`, pytest, Git; one worker and one numeric thread.

def build_feature_row(row, *, feeder_kva):
    audit = row["baseline_audit"]
    return {
        "offer_stress": abs(float(row["f_bal_kw"])) / feeder_kva[row["feeder"]],
        "voltage_margin": min(float(audit["vmin"]) - 0.95,

        "transformer_margin": 1.0 - float(audit["transformer_loading_max"]),
        "feeder_margin": 1.0 - float(audit["feeder_loading_max"]),
        # deterministic categorical main effects and limited interactions
    }

Use `beta = beta_pos - beta_neg`, `y - X beta = u - v`, pinball residual cost divided by `n`, and L1 coefficient penalties. Set the forbidden sign component upper bound to zero for the five physical coefficients.

objective = np.r_[penalty_vector, penalty_vector,
                  np.full(n, quantile / n),
                  np.full(n, (1.0 - quantile) / n)]
A_eq = np.hstack([X, -X, np.eye(n), -np.eye(n)])
solution = scipy.optimize.linprog(
    objective, A_eq=A_eq, b_eq=y,
