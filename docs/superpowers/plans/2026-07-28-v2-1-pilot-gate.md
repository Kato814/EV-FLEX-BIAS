# V2.1 16-Work-Unit Pilot Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and execute a recoverable, single-worker 16-work-unit audit that decides whether EV-FLEX-BIAS should proceed to a formal V2.1 rerun.

**Architecture:** Keep all frozen V2.0 artifacts immutable. Add a V2.1-pilot-only manifest, a corrected in-memory OpenDSS adapter, a full-horizon schedule-transfer audit, a lexicographic phase-balancing tie-break, and a machine-readable multi-axis gate. Raw pilot work-unit JSON files live in a dedicated tracked namespace and are aggregated only after all 16 units terminate.

**Tech Stack:** Python 3.12, NumPy, pandas, SciPy HiGHS, OpenDSSDirect.py, pytest, Git worktree.

---

## Frozen scientific decisions

- Exactly 16 work units and 48 evaluations:
  - feeders: `ieee13`, `lv906`;
  - call times: `19:00`, `00:00`, `02:00`, `06:00`;
  - directions: `inc`, `dec`;
  - durations per work unit: `15`, `30`, `60` min.
- The eight scenario IDs are the pre-existing frozen regression cases:
  - `ieee13_1900_17`, `ieee13_0000_09`, `ieee13_0200_17`, `ieee13_0600_24`;
  - `lv906_1900_18`, `lv906_0000_11`, `lv906_0200_03`, `lv906_0600_02`.
- Pilot data role is `development_pilot`; it is never a formal holdout.
- Formal truth constraints:
  - all 96 intervals;
  - all energized bus-phase voltage nodes;
  - VUF at every energized three-phase bus;
  - every transformer with an explicit positive kVA rating;
  - feeder apparent power at the declared 5000 kVA or 800 kVA rating, with no hidden 1.10 multiplier;
  - line thermal constraints excluded because the supplied DSS files contain no explicit traceable ampacity.
- Active offer:
  - `f_bal_kw >= max(7.2, 0.005 * feeder_kva)`;
  - inactive offers have no `alpha_transfer` and never enter safety/coverage denominators.
- Transfer path:
  - coarse alpha grid step `0.02`;
  - boundary refinement tolerance `0.002`;
  - use `alpha_prefix` for conclusions;
  - record `alpha_sup` and non-monotonicity; never use binary search across a detected non-monotone path.
- Resource policy:
  - one process;
  - one numerical thread;
  - one work unit per child process;
  - atomic JSON checkpoints and `--resume`.
- Online direct-audit latency budget is 5 s per schedule. Screening is dropped if warm p95 full-audit latency is at most 1 s on both feeders.
